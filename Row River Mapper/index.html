Upload checklist for iMapInvasives

  • Bulk upload is done by a Jurisdiction Admin on the website. Send them the CSV.
  • The file has no Observer column. The Jurisdiction Admin sets the observer as a default value in the bulk upload tool, and that person must already exist in iMapInvasives.
  • Coordinates are decimal degrees (WGS84). Lines and areas get their center point, plus the full shape as WKT in the “Geometry WKT” column.
  • Records with the same location, species and date as an existing record are rejected.
